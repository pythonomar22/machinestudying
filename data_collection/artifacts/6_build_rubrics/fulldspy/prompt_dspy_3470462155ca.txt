- Question: `I want to trace prompt construction across repeated `dspy.Predict` calls without unbounded memory growth. What is the difference between DSPy's prompt history and its execution trace, and how do their limits behave?`
- Gold answer:
They are separate stores. Prompt history is written by the LM layer and keeps raw LM-call artifacts such as formatted `messages`, request kwargs, and raw outputs. Execution trace is appended by `Predict` after parsing and stores `(predictor, input_kwargs, Prediction)`. `max_history_size` and `disable_history` govern LM/module history, while `max_trace_size` governs `dspy.settings.trace` and `trace=None` disables trace appends entirely. Global history has its own 10,000-entry cap.

```python
import dspy
from dspy.clients.base_lm import GLOBAL_HISTORY
from dspy.utils.dummies import DummyLM

GLOBAL_HISTORY.clear()
lm = DummyLM([{'answer': 'Paris'}] * 10)
dspy.configure(lm=lm, trace=[], max_trace_size=3, max_history_size=5)

assert len(dspy.settings.trace) == 3
assert len(pred.history) == 5
```
