- Gold answer:
These optimizers mutate signature objects, not a hidden template. In this repo, COPRO rewrites the signature instructions and also writes a new `prefix` into the last output field's metadata. GEPA rewrites instructions only. The built-in chat/json prompt builders render visible field headers from field names plus descriptions/type info, not from `prefix`, so an optimized prefix survives in metadata and saved state but does not appear in today's rendered prompt unless you write an adapter that reads it.
