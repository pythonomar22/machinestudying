- Question: `If I wrap a program in a module that samples several rollouts and then keeps only the best one, why can the final DSPy trace show just one candidate run, and which run is preserved?`
- Gold answer:
`dspy.Predict` traces each underlying predictor call, but `BestOfN` and the rollout loop inside `Refine` deliberately isolate each candidate under a temporary `trace=[]`, copy that rollout's trace, score it, and only splice back the currently best rollout at the end. So you do not get a concatenated trace of every candidate run. In `Refine`, helper predictor calls outside that temporary context can still appear separately, while reward-function tracing is excluded because the rollout trace is copied before scoring.
