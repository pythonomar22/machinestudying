- Gold answer:
`dspy.Parallel` directly accepts `Example`, `dict`, and `tuple` payloads. It also accepts a `list`, but only for the special case where the callee's class name is exactly `Parallel`, which is how nested parallel sub-runs are routed. `Example`s are unpacked via `.inputs()`, dicts become keyword calls, tuples become positional calls, and other payload types raise `ValueError`.
